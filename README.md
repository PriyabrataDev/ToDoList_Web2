# Todo List

A simple task list built with React and Vite. Add, edit, complete, filter, and
delete tasks in the browser.

## Run locally

Install Node.js, then run:

```sh
npm install
npm run dev
```

Vite prints the local URL when the development server starts. To check the
project, run `npm run lint` and `npm run build`.

This app does not use external APIs, so no API keys or credentials are
required.
